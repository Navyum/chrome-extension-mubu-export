常见问题

关于幕布导出工具的疑问解答

幕布导出工具是免费的吗？
完全免费且开源。你可以在 Chrome 应用商店直接安装，无需付费、无广告、无使用次数限制。源码托管在 GitHub，欢迎审查和贡献。
支持哪些导出格式？
支持 7 种格式：Markdown（.md）、OPML（兼容 XMind/Logseq）、Freemind（.mm 思维导图）、HTML（可分享网页）、Word（.doc）、PDF（.pdf）、JSON（原始数据）。所有格式都完整保留文件夹层级和备注内容。
需要幕布会员才能使用吗？
不需要。工具使用你的登录状态直接读取文档数据，和会员等级无关。免费账号即可使用全部导出功能。
导出会影响幕布上的原始数据吗？
完全不会。工具只是读取数据并在本地转换格式，不会修改、删除或上传你在幕布上的任何内容。所有操作都在你的浏览器本地完成。
导出过程中断了怎么办？
工具内置断点续传功能。如果因为网络波动或关闭浏览器导致中断，重新打开后点击继续即可从上次的位置恢复，无需从头开始。
数据安全有保障吗？
所有操作完全在本地浏览器内完成，不经过任何第三方服务器。工具只读取幕布的浏览器 Cookie 用于认证，不存储、不上传任何用户数据。代码完全开源可审计。
